# Text-Summarizer
An intelligent abstractive text summarization web application built using the T5 Transformer model, Flask, and Hugging Face Transformers. This project allows users to input long paragraphs or documents and instantly generate concise, meaningful summaries.

It is designed to demonstrate practical Natural Language Processing (NLP) and Transformer-based text generation in a real-world application.

# Tech Stack
Python

FastApi

Hugging Face Transformers

PyTorch

HTML / CSS

Jupyter Notebook
